# Мой Портфолио

Современный портфолио-сайт, размещённый на GitHub Pages.

## 🚀 Быстрый старт

1. **Форкни репозиторий** или клонируй его:
```bash
git clone https://github.com/username/username.github.io.git
cd username.github.io
```

2. **Открой `index.html`** в браузере локально или жди публикации на GitHub Pages.

3. **Дай доступ GitHub Pages**:
   - Перейди в Settings → Pages
   - Выбери Branch: `main` (или тот, где находится код)
   - Сохрани

Сайт будет доступен по адресу: `https://username.github.io`

## 📁 Структура проекта

```
.
├── index.html      # Главная страница
├── styles.css      # Стили
├── script.js       # JavaScript логика
└── README.md       # Этот файл
```

## ✨ Функции

- **Адаптивный дизайн** — хорошо выглядит на всех устройствах
- **Плавная прокрутка** — интерактивная навигация
- **Карточки проектов** — с анимацией при скролле
- **Современный стиль** — неоновая тематика с чёрным фоном

## 🎨 Кастомизация

### Цвета
В `styles.css` меняй `:root` переменные:
```css
:root {
    --primary: #1a1a2e;     /* Основной цвет фона */
    --secondary: #16213e;   /* Дополнительный цвет */
    --accent: #00d4ff;      /* Цвет акцентов */
    --text: #ffffff;        /* Основной текст */
    --text-light: #a0a0a0;  /* Лёгкий текст */
}
```

### Контент
1. Меняй текст в `index.html`
2. Добавляй свои проекты в секцию `.projects`
3. Обновляй ссылки на контакты

## 🔗 Добавь свои проекты

В HTML найди `project-grid` и добавляй карточки:
```html
<div class="project-card">
    <div class="project-icon">🎮</div>
    <h3>Название</h3>
    <p>Описание</p>
    <a href="путь-или-ссылка" class="project-link">Играть →</a>
</div>
```

## 📝 Файлы для редактирования

- **index.html** — главная структура страницы
- **styles.css** — оформление и цвета
- **script.js** — интерактивные элементы

## 🌐 Опубликуй на GitHub Pages

1. Создай репозиторий: `username.github.io`
2. Залей туда эти файлы
3. Жди ~5 минут
4. Переходи на `https://username.github.io`
